# Data Dictionary

- market_data.csv: VNINDEX, thanh khoản, thị phần ước tính.
- branch_performance.csv: doanh thu môi giới, AUM, margin, active clients theo chi nhánh.
- product_pnl.csv: doanh thu, chi phí, lợi nhuận theo sản phẩm.
- rm_performance.csv: doanh thu, khách hàng, AUM theo RM.
- customer_behavior.csv: hành vi khách hàng, churn risk, product usage.
- competitor_benchmark.csv: benchmark công ty chứng khoán.
- okr_initiatives.csv: sáng kiến, owner, tiến độ, rủi ro.
